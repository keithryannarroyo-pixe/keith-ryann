MotoGarage website
==================
Open index.html in a browser (no install needed).

index.html        the page
src/shop.css      all styling
src/shop.js       bikes, specs, PRICES (the D list), accessories (ACC list), currency (CUR), slideshow, cart, wishlist, checkout
public/bikes/     the 10 bike cut-outs (0.webp = first bike in the D list, 1.webp = second, ...)
src/assets/       your original uploaded images, untouched
src/old-react/    your previous React files, kept for reference only (not used)

Prices are placeholders - edit p: values in src/shop.js.
